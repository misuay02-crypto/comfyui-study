# comfyui-study

面向初学者的中文 ComfyUI 离线学习桌面应用。v1.0.0 提供前四阶段的 12 节课程，以及学习进度、笔记、资料库和跨电脑备份。

## 下载与安装

[下载 comfyui-study v1.0.0 Windows x64 安装包](https://github.com/misuay02-crypto/comfyui-study/releases/download/v1.0.0/comfyui-study-Setup-v1.0.0-x64.exe) · 116.6 MiB · 未签名

1. 下载 `.exe` 并运行安装向导。可选择自定义安装目录。
2. 首次启动时选择个人数据目录，例如 `D:\ComfyUIStudyData`。如果没有 D 盘，可选择其他有写入权限的独立文件夹。
3. 在学习首页打开课程，或从上次的位置继续。内置课程、笔记、资料管理和备份可离线使用，无需注册账号或另装 Node.js。

安装包已在 Windows 11 x64 上验证。可用 PowerShell 在下载目录计算文件校验值，并与下面的 SHA-256 比对。

```powershell
Get-FileHash -Algorithm SHA256 -LiteralPath '.\comfyui-study-Setup-v1.0.0-x64.exe'
```

## v1.0.0 功能

- 12 节离线课程共约 308 分钟。涵盖生成模型、本地运行基础、ComfyUI 入门、工作流接线、扩散与采样参数。配有分层解释、术语、练习、课内自测和教学工作流示意。
- 保存阅读位置和已读标记，记录课程活跃学习时长。支持文字笔记、中文全文检索和资料原件导入。
- 支持完整或增量 `.aistudy` 备份、导入预览、冲突处理和附件恢复。可在设置中迁移或切换本机数据目录。

## 在两台电脑间续学

1. 在第一台电脑打开「备份与迁移」，导出完整 `.aistudy` 备份。
2. 用微信文件传输助手或其他可信方式发送备份。第二台电脑在应用中打开文件，预览后确认导入。
3. 后续可以导出增量。若提示缺少基线，先按顺序导入完整包和缺少的增量。两边修改同一条记录时，可选择保留本地版本、采用导入版本或保留两份。

备份文件上限为 64 MiB，未加密。建议保留完整包和后续增量，直至确认另一台电脑可以读取学习记录和资料。
